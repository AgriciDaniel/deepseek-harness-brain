# Support

Support is best effort and has no service-level agreement.

## Supported here

- Installation and command-line behavior.
- Checkout import, synthesis, vault lint, and deterministic demo generation.
- Report generation and portability-brain navigation.
- Reproducible bugs in the template or sample vault.
- Corrections to evidence, claims, citations, or confidence labels.

## Not supported here

- Upstream DeepSeek Harness product support.
- Production deployment or live-provider incidents.
- Security guarantees or penetration testing.
- Private client consulting or review of sensitive vault contents.

For a reproducible bug, use the bug-report form. For a disputed or stale claim,
use the evidence-correction form. Include the brain version, Python version,
operating system, exact command, vault type, and sanitized output.

Sensitive issues belong in the private route described in `SECURITY.md`.
