# DeepSeek Harness README

## What It Says

- DeepSeek Harness describes itself as an open-source agent harness where everything is a plugin.
- The project is in developer preview and explicitly allows compatibility-breaking changes.
- The documented source workflow is pnpm install, pnpm run build, then pnpm dsh web.
