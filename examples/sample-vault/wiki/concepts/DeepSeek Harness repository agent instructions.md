# DeepSeek Harness repository agent instructions

## What It Says

- New behavior belongs on documented plugin extension points rather than in the agent loop.
- Model-visible inputs must be reconstructable from the session log.
- Registrations are reversible effects and capability seams require definition, provider, and consumer roles.
