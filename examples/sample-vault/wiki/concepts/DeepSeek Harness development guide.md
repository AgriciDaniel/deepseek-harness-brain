# DeepSeek Harness development guide

## What It Says

- The repository supports Node 22.19 and later in the 22 line, plus Node 24 and later, with pnpm 11.7.0.
- Host and Client compile as separate TypeScript aggregate programs because their Cordis Context merges would collide.
- Built-artifact consumers require a preceding build.
