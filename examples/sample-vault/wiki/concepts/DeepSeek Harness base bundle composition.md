# DeepSeek Harness base bundle composition

## What It Says

- The shipped base profile defaults to workspace-write sandbox mode and ask approval unless explicitly overridden.
- Danger-full-access pairs an unrestricted sandbox mode with never-ask approval.
- The base composition mounts service, policy, provider, tool, persistence, compaction, subagent, workflow, and Web-search rows.
