# DeepSeek Harness architecture

## What It Says

- Profiles stack bundles and patch layers over an initially empty Cordis entry list.
- Session events are durable facts while agent and capability events control live work.
- The core turn flow admits input, assembles prompt and tools, streams a model request, executes tools, and closes the turn.
