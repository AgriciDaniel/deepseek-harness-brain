# Visual Asset Provenance

This directory contains the project-owner cover and two supporting illustrations.
All repository copies were stripped of metadata and optimized for GitHub use.

## Files

- `deepseek-harness-second-brain-cover.jpg`: project-owner cover, optimized from
  a 2172 by 724 PNG to a 2172 by 724 JPEG at quality 98. The repository copy is
  435,852 bytes. The Desktop source was not overwritten.
- `deepseek-harness-brain-hero.webp`: alternative original repository artwork.
- `portable-harness-modules.webp`: documentation illustration for the portability flow.

## Design boundary

The two WebP illustrations were generated specifically for DeepSeek Harness Brain
on 2026-08-21 with OpenAI's built-in image-generation tool. Their deep-ocean
systems metaphor and navy, cobalt, and cyan palette are original. The official
DeepSeek Harness site was reviewed only for broad design context. No site artwork
or product screenshot was copied.

The project-owner cover contains the DeepSeek name and whale mark. It is used to
identify the research subject. The repository's independent-project notice must
remain prominent wherever this cover is used.
