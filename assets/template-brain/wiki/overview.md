# Overview

DeepSeek Harness Brain is a persistent, source-cited architecture and portability brain for the pinned developer-preview Harness checkout. It separates durable session facts from live coordination, tool authority from presentation, filesystem confinement from broader security, and executed checks from unverified tiers.

![[brain-relationship-map.svg]]

Start with [[DeepSeek Harness Review Verdict]] for the decision, [[DeepSeek Harness System Dissection]] for the full map, [[Cordis Fork Delta]] for the local framework delta, and [[Portability Matrix]] for what to reuse. [[Keyless Architecture Verification Results]] records the executed local evidence and its limits.

The strongest reusable slice is the combination of append-only session events, request reconstruction, a single guarded tool pipeline, capability seams, explicit approval, and ownership-first disposal. Dynamic profiles, workflows, and generated Web RPC are lower-priority ports because they bring more framework and operational cost.
